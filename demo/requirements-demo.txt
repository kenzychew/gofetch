# Pinned deps for the single-process demo (demo/app.py).
#
# Versions match what's already resolved in the repo's uv.lock, so this is
# the same code path the Docker Compose backend runs -- demo/app.py just
# imports src.api.main:app directly, it doesn't reimplement any of it.
#
# torch is pinned to the CPU-only wheel index: none of the pipeline's local
# models need a GPU (embedder is all-MiniLM-L6-v2, reranker is
# cross-encoder/ms-marco-MiniLM-L-6-v2, both ~80MB and fast enough on CPU for
# demo traffic), and pulling the default CUDA-bundled torch wheel would
# roughly triple the image size for no benefit here.
